# 公开协作版范围

本仓库通过白名单从内部工作区生成，只保留继续开发所需的源码、测试、示例配置和技术文档。

未发布内容包括：

- 真实公司、员工、客户、供应商和联系人身份信息；
- API Key、Token、Cookie、密码、SSH 信息和服务器地址；
- 生产环境 `.env`、运行时配置和部署快照；
- CRM 数据库、线索数据、邮件、消息、报表、日志和审计输出；
- `node_modules`、缓存、覆盖率、编译目录和临时目录；
- ZIP、安装器、可执行文件及其他发布产物；
- 网站上传文件、商品图片和内部权属材料；
- 个人工作记忆、交接记录和备份。

仓库中的公司名、姓名、地址、电话、邮箱和域名均为示例值。任何协作者在提交前都应再次检查变更，确认没有把本地配置或真实业务数据带入 Git 历史。
