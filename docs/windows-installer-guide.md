# CRM Agent Windows 一键安装器使用说明

## 1. 选择安装包

- 普通 Intel/AMD Windows 10、Windows 11：使用 `x64-Setup.exe`。
- Windows ARM64 电脑：使用 `arm64-Setup.exe`。
- 没有管理员权限或只想先试运行：使用对应架构的 `Portable.exe`。
- Setup 版会创建开始菜单和桌面快捷方式；Portable 版每次启动会先解压，启动稍慢。

支持 Windows 10 1809 及以上版本。正式建议使用 Windows 10 22H2、Windows 11 或带桌面体验的 Windows Server 2019/2022/2025。

## 2. 安装前准备

开始前一次性准备以下资料，密码和密钥只保存在客户电脑的 Windows DPAPI 加密存储中，不写入诊断报告或部署压缩包。

### 公司与产品

- 英文公司法定名、品牌名、官网、国家、城市、英文地址。
- 联系人姓名、职位、邮箱和 WhatsApp。
- 产品名、HS Code、主要规格、卖点、目标市场、买家类型、MOQ、交期和报价规则。

### AI 与搜索

- AI API Base URL、模型名和 API Key。
- 搜索方式：自建 SearXNG、Serper 或 Exa。
- 选择 Serper/Exa 时准备对应 API Key；SearXNG 由安装器在服务器自动部署。

### 飞书或 Lark

- App ID、App Secret、CRM 名称。
- 在开放平台启用机器人、所需权限、WebSocket 长连接和消息事件，并发布应用。
- 中国企业选择飞书；海外企业选择 Lark。

### 邮箱

- Gmail 试运行或企业邮箱。
- 发件人名称、发件邮箱、回复邮箱。
- SMTP/IMAP Host、Port、用户名和应用密码。
- 每日/每小时发送上限、公司地址和退订文案。
- 企业邮箱还需完成 SPF、DKIM、DMARC 和邮箱预热。

### WhatsApp（可选）

- Graph API 版本、Phone Number ID、Access Token、App Secret、Webhook Verify Token。
- 已审核模板名称、语言代码、公开 HTTPS Webhook 地址和每日上限。

### Ubuntu 服务器

- Ubuntu 22.04 或 24.04 公网服务器。
- IP/Host、SSH Port、SSH 用户、一次性密码或私钥。
- 使用 root，或为专用部署用户配置免密 `sudo`。

## 3. 安装流程

1. 打开安装器，填写三个页面中的全部必填信息。
2. 点击“保存并开始安装”。
3. 安装器依次验证 Windows、飞书、邮箱、AI/搜索、WhatsApp 和服务器。
4. 第一次连接服务器时，核对服务商控制台显示的 SSH 指纹，再确认继续。
5. 安装器在服务器自动安装 Node.js、PowerShell、Docker Engine、Docker Compose、SearXNG、Agent 服务、备份定时器和数据库。
6. 安装器自动创建飞书多维表格。
7. 出现“绑定飞书”阻塞时，在飞书私聊发送 `绑定 配对码`，在销售群发送 `绑定群 配对码`。
8. 返回安装器点击继续。最终验收通过后状态显示 `COMPLETED`。

安装完成时，全局外发仍保持暂停。这样可以先检查 CRM、邮箱和命令入口，不会因误操作直接群发。

Gmail 免费试运行需要在飞书完成一次显式启用：

1. 发送 `状态`，确认“外发开关：开启、Gmail 自测：未通过、Gmail 试发授权：未启用、全局暂停：是”。
2. 发送 `测试 Gmail`。系统只向发件 Gmail 自身发送一封真实自测邮件。
3. 在 Gmail 收件箱确认收到自测邮件。
4. 返回飞书发送 `开启 Gmail 试发`，阅读限额和停止条件后点击“确认启用真实试发”。
5. 再发送 `状态`，确认“Gmail 自测：已通过、Gmail 试发授权：已启用、全局暂停：否”。

`恢复系统` 只能恢复已经完成首次启用的试运行，不能绕过 Gmail 自测和确认卡片。

## 4. BLOCKED、FAILED 与断点恢复

- `BLOCKED`：需要人工完成平台操作。完成后点击“继续”，不会从头安装。
- `FAILED`：网络、认证或服务器命令失败。修正后点击“重试”，从失败步骤继续。
- 关闭安装器、电脑重启或网络中断：重新打开后，已完成步骤和远程任务编号仍然保留。
- 远程部署失败：服务器自动恢复上一版本；再次重试会复用已上传的部署包。
- “回退”：按相反顺序回退安装器拥有的可逆变更。不会删除客户的飞书表、Docker 或共享系统组件。

## 5. 安装后使用

日常不需要打开 Codex。通过飞书或 Lark 给机器人下达指令，例如：

```text
开发马来西亚工业设备经销商50家，主推化工泵和OEM配件，只保留近期活跃、具名负责人和已验证邮箱的客户。
```

Agent 自动完成搜索、公司活跃度核验、联系人验证、评分、邮件草稿和 CRM 写入。首封触达必须人工批准。收到价格、MOQ、交期、参数、样品或报价相关回复后，Agent 立即发送飞书询盘通知并停止自动跟进，由销售人工接管。

## 6. 故障资料

安装器中的“导出诊断”只包含步骤状态、脱敏日志、Windows/Node/Electron 版本，不包含密码、API Key、App Secret 或邮箱应用密码。

提交故障时提供：

- 诊断 JSON。
- 当前状态和失败步骤名称。
- 服务器系统版本和服务商。
- 平台报错截图，但必须遮盖密钥和密码。
